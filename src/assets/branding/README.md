# Brand assets

The uploaded circular Gowsalya Cake Shop logo is stored at
`public/gowsalya-splash-logo.png` and is used in the splash screen, navbar and
footer. Keep its square aspect ratio so the complete circular artwork remains
visible at every size.

`src/assets/branding/banner.svg` is the wide decorative banner asset. The
legacy `logo.svg` remains in the repository but is not used for the current
site logo.
