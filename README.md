# Gowsalya Cake Shop

Premium single-page website for **Gowsalya Cake Shop** — homemade cakes, cookies,
brownies, cupcakes, customized cakes and chocolate varieties, baked fresh in
Thirumangalam, Madurai. Every order flows through WhatsApp, so there is no cart or
payment backend.

**Live demo sections:** Hero → Categories → About → Featured Products → Why Choose Us →
Custom Cake → Gallery → Testimonials → Order Form → Contact, plus an intro splash
screen and a floating WhatsApp button.

## Tech stack

| Layer      | Choice                                                    |
| ---------- | --------------------------------------------------------- |
| Framework  | React 19 (`src/main.jsx`, `src/App.jsx`)                   |
| Build tool | Vite 8 with the Rolldown bundler (`vite.config.js`)        |
| Styling    | Tailwind CSS 4 via `@tailwindcss/vite` (`src/index.css`)   |
| Animation  | Framer Motion + custom reveal/cursor components            |
| Icons      | lucide-react                                               |
| Fonts      | Playfair Display, Outfit, Great Vibes (Google Fonts)       |

## Getting started

```bash
npm install       # install dependencies
npm run dev       # dev server on http://localhost:5173 (host: true → LAN accessible)
npm run build     # production bundle in ./dist
npm run preview   # serve the built bundle on http://localhost:4173
```

`node_modules`, `dist`, `.env*` and local debug dumps are git-ignored — the bundle is
generated by `npm run build`, never committed.

## Project structure

```
index.html                  SEO meta, Open Graph, Bakery JSON-LD schema
vite.config.js              Vite + React + Tailwind plugins, manual chunk splitting
public/                     favicon, og-image, splash logo, robots.txt, sitemap.xml
src/
  App.jsx                   Section order and page shell
  components/sections/      Navbar, Hero, Categories, About, ProductShowcase,
                            WhyChooseUs, CustomCake, Gallery, Testimonials,
                            OrderForm, Contact, Footer
  components/ui/            Brand, Button, cards, Lightbox, LazyImage, SectionHeading
  components/decor/         CursorGlow, FrostingBlobs/SugarDivider, FloatingDecor, Reveal
  data/                     Single source of truth: shop, products, gallery,
                            testimonials, nav, images
  hooks/                    useActiveSection, useCountUp, useDevice, useScrolled,
                            useBodyScrollLock
  lib/                      whatsapp.js (link builder), device.js
  assets/branding/          logo.svg, banner.svg (see its own README)
tools/                      Playwright measure/verify scripts + og-image generator
```

## Editing content

* **Shop info (phone, address, hours, email, maps):** `src/data/shop.js`
* **Products / prices:** `src/data/products.js` (prices shown as “Contact for Price”)
* **Gallery & testimonials:** `src/data/gallery.js`, `src/data/testimonials.js`
* **WhatsApp number:** `src/lib/whatsapp.js` — used by every order button
* **Branding artwork:** swap the files in `src/assets/branding/` (instructions in
  `src/assets/branding/README.md`)

## Deploying

Build a static bundle and host `dist/` on any static host (Netlify, Vercel,
GitHub Pages, cPanel):

```bash
npm run build
```

Update the canonical/Open Graph URLs in `index.html` and `public/robots.txt` if the
final domain differs from `gousalyacakeshop.in`.
